# Playwright Docker Setup

Run Playwright E2E tests with the CARE backend using Docker.

## Quick Start

```bash
./scripts/run-playwright-docker.sh
```

## Files

- `Dockerfile.playwright` - Custom Docker image
- `docker-compose.playwright.yml` - Test orchestration
- `scripts/run-playwright-docker.sh` - Helper script
- `scripts/validate-playwright-docker.sh` - Setup validation
