# Contributing to CARE Frontend

Thank you for your interest in contributing to CARE Frontend.

## Contribution Guidelines

- Create a branch from the latest `develop` branch using the format  
  `issues/{issue#}/{short-name}`  
  (example: `issues/7001/edit-prescriptions`).

- Once your changes are ready, open a pull request with a meaningful title  
  (example: `💊 Adds support for editing prescriptions #6369`).

- Ensure the related issue number is mentioned in the PR description using a closing keyword.

- After code review, the PR will be marked as **Needs Testing** and queued for QA.

- Once testing is complete, the PR will be marked as **Tested** and queued for merge.
